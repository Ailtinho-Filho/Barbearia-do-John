# 💈 Barbearia do John

Site fictício de uma barbearia com landing page completa e sistema de agendamentos CRUD.

## 🔗 Demo

[Acesse o projeto](https://ailtinho-filho.github.io/Barbearia-do-John)

---

## 📋 Sobre o Projeto

Projeto acadêmico desenvolvido para praticar HTML, CSS e JavaScript puro. Simula o site de uma barbearia fictícia com informações dos serviços e um sistema de agendamentos funcional.

---

## ✨ Funcionalidades

- **Landing page** com navbar fixa, hero, serviços e footer
- **CRUD de agendamentos** completo:
  - ✅ Criar agendamento (nome, serviço, data/hora)
  - ✅ Listar agendamentos em tabela
  - ✅ Editar agendamento existente
  - ✅ Cancelar/deletar agendamento
- **Persistência de dados** via localStorage (os dados ficam salvos no navegador)
- **Design responsivo** — funciona no celular e desktop

---

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura da página |
| CSS3 | Estilização e responsividade |
| JavaScript | Lógica do CRUD e manipulação do DOM |
| localStorage | Persistência dos agendamentos |

## 🚀 Como rodar

1. Clone o repositório:
```bash
git clone https://github.com/Ailtinho-Filho/Barbearia-do-John
```

2. Abra o arquivo `index.html` no navegador

Não precisa de servidor ou instalação — roda direto no browser.
